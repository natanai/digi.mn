# digi.mn

A text-led, 2D pixel-art Digimon fan game set in the *Digimon Beatbreak* universe, built around a Cleaner accepting procedurally composed bounties while following a persistent authored story.

**Status:** Concept foundation recorded. The gameplay engine has **not yet been copied or implemented** in this repository.

## Canonical design

Read [Game design and first playable milestone](docs/game-design.md) for the agreed direction, technical starting point, the nonviolent-resolution guarantee, Sapotama partner reveal, and the initial vertical slice.

## Starting point

The intended technical foundation is a separate snapshot of [pre-programmed](https://github.com/natanai/pre-programmed), keeping its narrative/state/authoring system while adding a side-on town renderer, a generated overhead bounty map, and story-driven encounters with optional animated cutaways.

This is an independent, unofficial fan project.
